# Student Grade Management System

## Project Overview
A Java-based console application designed to manage student records and calculate academic performance using Object-Oriented Programming principles.

## Technologies Used
- Java (JDK 17+)
- Object-Oriented Programming (OOP)
- Java Collections (ArrayList)
- Exception Handling
- File Handling (CSV)

## Features
- Add Student
- Display All Students
- Update Student Marks
- Calculate Total Marks
- Calculate Percentage
- Calculate Class Average and Median
- Generate Student Report Cards
- Find Topper

## Dataset
The project uses a CSV dataset containing student IDs, names, and marks in four subjects:
- Mathematics
- Science
- English
- Computer
